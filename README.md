# مشاريعي في ربط الأنظمة عبر الـ API

**فياض محمد عبد**

أنشطة ومشاريع عملية أعددتها بالاعتماد على محاضرات **الأستاذ المساعد الدكتور أمير هادي**. موضوعها تناقل البيانات بين المنصات عبر الـ API باستخدام التوكن.

> أُعدّت هذه المشاريع بمساعدة Claude.

## ما تعلمته في هذه المشاريع

- **مفهوم الـ API:** المسارات (Endpoints)، وأنواع الطلبات `GET` و`POST` و`PUT` و`DELETE`.
- **المصادقة:** تسجيل الدخول باسم مستخدم وكلمة مرور، ثم استخدام توكن `Bearer`.
- **الـ API Client:** حفظ التوكن، وتجديده عند انتهائه، وإعادة الطلب تلقائياً.
- **رموز الردود:** `200` و`201` و`401` و`403` و`404` و`409` و`422`، وطريقة التعامل مع كل منها.
- **الأمان:**
  - تشفير كلمات المرور.
  - حفظ التوكن مشفّراً في قاعدة البيانات.
  - الربط من خادم إلى خادم، حتى لا يظهر التوكن في المتصفح.
- **التشغيل:** على XAMPP، والوصول من الحاسبات الأخرى في الشبكة.

## التشغيل السريع

| المشروع | الأمر أو الرابط |
|---|---|
| 3 (Node.js) | `node start.js`، ثم افتح `http://localhost:4000` |
| 4 (XAMPP) | انسخ `central` و`organized_crime` إلى `C:\xampp\htdocs\`، ثم افتح `http://localhost/central/install.php` |

تفاصيل كل مشروع موجودة في ملف `README.md` داخل مجلده.

> **تنبيه:** كلمات المرور الموجودة في المشاريع (مثل `Admin@123` و`Crime@2026`) للتجربة فقط، والأسماء في البيانات التجريبية افتراضية.
